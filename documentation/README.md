# Kakuma Connect

**Project Theme:** Local Experience & Professional Networks

**Sustainable Development Goals:** SDG 8, SDG 10 and SDG 17

## About the Project
Kakuma Connect is a community digital platform that connects local businesses, freelancers and customers in Kakuma.

## Technologies
- HTML
- CSS
- JavaScript

## Main Features
- Homepage and navigation
- Local product listings
- Product search and category filters
- Shopping cart and checkout form
- Freelancer registration
- Contact form

## How to Run the Project
1. Open the Kakuma-Connect folder.
2. Locate `index.html`.
3. Right-click and select Open with Google Chrome.

## Project Documentation
The documentation folder contains the project report and website screenshots.

## Future Development
MySQL database integration, user accounts and online payment features will be considered in future development.
